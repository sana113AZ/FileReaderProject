# FileReaderProject

## 📌 Description
A simple C++ program that reads a text file (`data.txt`) and counts:
- Digits
- Lowercase letters
- Uppercase letters
- Other characters

It also asks the user to enter their name and prints it with the results.

---

## 📂 Files
- `Source.cpp` → main C++ program
- `data.txt` → sample text file for testing
